How to install

  1. Plug Billy into your computer with a USB-C data cable. Charge-only cables won't work.
  2. Click Install / Update SassyBass and choose the port that appears, usually "USB JTAG/serial debug unit".
  3. If no port shows up, hold the board's BOOT button, tap RESET, release BOOT, and try again.
  4. Wait for it to finish (about a minute), then unplug and plug Billy back in.

Updating a fish that already works?

When it asks "Erase device?", leave it unchecked. Erasing wipes the saved Wi-Fi and AI key.

You usually don't need this page for updates. Billy checks for new firmware over Wi-Fi every time he starts.

First-time setup

  1. Billy's light turns purple. On your phone, join the Wi-Fi network BillyBass-Setup (password billybass).
  2. The setup page opens. If it doesn't, go to http://192.168.4.1. Pick your home Wi-Fi and enter its password.
  3. Say "Hi E-S-P", chat away, and say "goodbye" when you're done.

Works in Chrome, Edge, and Firefox on a computer, and in Chrome on Android. iPhone and iPad aren't supported. Source: github.com/snydergj/SassyBass
